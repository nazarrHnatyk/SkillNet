
# 💻 SkillNet

**SkillNet** is a platform that connects IT freelancers with clients, helping professionals find freelance projects and businesses find skilled specialists.

## 📌 About the Project

SkillNet aims to make freelance work easier by bringing clients and IT specialists together in one convenient platform.

Whether you're looking for your next project or searching for someone to bring your ideas to life, SkillNet helps you connect.

## 🎯 Key Features

- 🔍 **Find Projects** — browse available freelance opportunities.
- 💼 **Post Projects** — publish jobs and find freelancers.
- 👨‍💻 **Find Freelancers** — discover specialists by skills and experience.
- 📋 **User Profiles** — showcase your skills and portfolio.
- ⭐ **Favorites** — save interesting projects.
- 🤖 **AI Assistant** — get help finding suitable freelance projects.
- 🌙 **Dark & Light Modes** — switch between two interface themes.

## 🎨 Design

SkillNet features a modern, minimalistic interface.

- **Dark Mode:** dark backgrounds with yellow gradients and accents.
- **Light Mode:** light backgrounds with blue gradients and accents.
- Responsive design.
- Clean navigation and user-friendly layout.

1. Clone or download the repository.
